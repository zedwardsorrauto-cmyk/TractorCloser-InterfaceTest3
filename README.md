# TractorCloser Interface Preview

This package contains the current front-end prototype for interface-level testing.

## Run locally

Open `index.html` in a browser. It routes to the TractorCloser interface and runs with preview data when no backend is connected.

## Deploy as a static site

Upload every file in this package to the root of a GitHub repository. For Render, create a Static Site from that repository and publish the repository root.

## Current scope

The application is a front-end prototype. Login, persistent data, integrations, reminders, and AI services will be connected during backend development.
